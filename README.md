- **Theme Engine**: Seamless **Dark & Light Mode** toggle with `localStorage` persistence and automatic system preference detection.

- **Modern Typography**: Google Fonts pairing with **Outfit** (headings) and **Inter** (body text).
- **Interactive Capabilities**:

## 💻 Local Development

### Option 1: Python HTTP Server (Recommended)
```bash
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Node / NPX
```bash
npx serve .
```

## 🚢 Deploy to Vercel

This is a static web application that can be deployed to Vercel instantly:

1. Push your code to GitHub:
   ```bash
   git add .
   git commit -m "Deploy Hari Hara Sudharsan Portfolio"
   git branch -M main
   git remote set-url origin https://github.com/hari-hara-sudharsan/portfolio-hari.git
   git push -u origin main
   ```
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import your GitHub repository `portfolio-hari`.
4. Click **Deploy**. Vercel will automatically build and host the site with continuous deployment on every git push.
